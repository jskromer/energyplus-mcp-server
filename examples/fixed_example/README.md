# Fixed Example

A ready-to-run EnergyPlus simulation example with IDF, weather data,
and a Python runner script.

Originally from the `EnergyPlus_Fixed_Example` repo, merged here
during consolidation (2026-03-22).

## Contents

- `idf_files/test.idf` — Test building model
- `weather_files/` — EPW weather files (USA, San Francisco TMY2)
- `scripts/run_simulation.py` — Python simulation runner
- `outputs/` — Sample simulation results
